# LabVIEW Training (French Edition)

This repository introduces the official French LabVIEW training program created and maintained by **Technologies de France**, a training and engineering entity belonging to the **Graiphic Group**.

The full training content is freely accessible and provides a complete learning path from absolute beginner to advanced LabVIEW architectures such as QMH, FGV, OOP, Actor Framework, Real-Time, FPGA, and hardware integration.

---

## 📘 What This Training Offers

- A complete **French-language curriculum** covering all major LabVIEW concepts  
- Step-by-step learning, from fundamentals to architecture-level design  
- More than **100 structured lessons**, each mapped to real engineering practices  
- Hardware-oriented chapters using NI, Advantech, ADLINK, Digilent and embedded SoC platforms  
- A strong focus on **industrial LabVIEW development**  
- Fully free, open, and maintained by Graiphic engineers

---

## 📚 Training Structure

The course is organized into thematic “seasons”, each addressing a major competency area:

### **Season 1 — Core Concepts**
Environment, structures, arrays, clusters, subVIs, state machine, QMH, FGV, CLD, CLA.

### **Season 2 — Advanced Programming**
Object-oriented programming (OOP), Actor Framework, .NET connectivity.

### **Season 3 — Data & Connectivity**
Data saving, registries, SQL databases, NI WebServer, UI design.

### **Season 4 — Hardware & LabVIEW**
USB DAQ, CompactDAQ, iDAQ, PXI/PXIe, industrial PCs, academic hardware, RT/FPGA systems, Raspberry Pi (LINX).  
Includes a **Bonus Chapter: RS232 universal control**.

## 🧩 About Graiphic

Graiphic builds advanced LabVIEW toolkits and ecosystem technologies, including:

- **SOTA**: a complete Deep Learning framework for LabVIEW  
- **GO-HW**: a hardware orchestration layer for test benches and embedded systems  
- **GO-GenAI**: deterministic graph-based generative AI execution in LabVIEW  
- **Advanced Execution Providers** for CUDA, TensorRT, ONNX Runtime, and edge devices  

By integrating LabVIEW expertise with modern AI and hardware acceleration, Graiphic provides a unique European ecosystem for test, measurement, deep learning, and embedded orchestration.
