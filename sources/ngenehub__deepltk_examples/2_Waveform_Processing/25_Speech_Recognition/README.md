# Speech Recognition

This example demonstrates speech (voice command) recognition with the help of [DeepLTK], where audio waveforms are converted into spectrogram images and classified with a CNN.

## Project Contents

> *This is a high-level overview of the project, with snapshots of the main VIs. <br>For detailed instructions, please refer to the [blog post].*
